# NEETPrep

A mobile-friendly NEET preparation MVP. The app does **not** include a small local question bank. Practice questions are generated by AI when a test is started.

## Features

- Subject and chapter selection
- Configurable question count and timer
- Fresh AI-generated NCERT-aligned practice questions
- Answer explanations and NCERT source references
- Responsive dashboard UI
- OpenAI or Gemini server-side integration

## Local setup

```bash
npm install
cp .env.example .env.local
npm run dev
```

Configure one AI provider in `.env.local`. API keys stay on the server and must never be placed in browser code or committed to Git.

## Privacy and accuracy

Generated questions are labeled as practice material. Past-year or real-exam questions should only be added from verified, properly licensed sources. All India Rank values must be presented as estimates, not official rankings.
