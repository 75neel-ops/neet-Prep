## Branding and desktop shortcut

The app identifies its owner as **NilanjanC** in the sidebar. Its browser tab icon is 📘 and the window title is **NEETPrep by NilanjanC**.

To put it on your Windows desktop in Chrome: open the deployed app, select Chrome's three-dot menu → **Cast, save, and share** (or **Save and share**) → **Create shortcut**, name it `NEETPrep`, and enable **Open as window** if offered. The shortcut launches the app like a separate window; the Chrome address bar and tabs can be hidden in that mode. The Streamlit Cloud app itself is still hosted by Streamlit, so Streamlit's hosting controls/branding cannot be removed from the hosted service. The custom NEETPrep icon artwork is in `assets/neetprep-icon.svg`.
